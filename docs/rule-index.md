# 规则索引（rule-index）

> **给维护者读。** 每一条硬规则一行：它防的是哪个失败、有没有机器在守它、上次被触发是什么时候。
> 用途：① 敢不敢删一条规则，看这里；② 新女仆翻车时，先查"这条有没有断言"；③ 审计时找"孤儿规则"（没人守、也没有教训支撑）。
>
> 维护约定：**新增规则必须三选一**——① 配一条断言（R/L2 场景），② 替换/删掉一条旧规则，③ 明确标注"只值一句话、不扩展"。§0（性格/北极星）豁免。
