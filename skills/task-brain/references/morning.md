## 晨间巡视(daily 闹钟唤醒时走这条)

1. **感知主人**:探针命令与节律表见 `references/heartbeat.md`(需要的再加看一眼眼睛)。
2. **读账本**:`ledger/tasks.md` 全文读一遍(含尾部"长期备注")。排序不靠数字,靠你的判断:硬截止 < 软目标 < 周期欠账 < 挂起。
3. **判定**:
   - `session_locked` 或 `idle_minutes > 30` → 主人还在睡:**沉默**,`schedule_create` after 30-60 分钟再巡视。
     若已是你今天第三次巡视且过了 10:30 → 改为礼貌提一句"今天有几件事要办"(见 SKILL.md 判定协议:时机对)。
   - `idle_minutes < 10` → 主人醒了:**早上好 + 晨报**。
     晨报 = 你判断最要紧的 2-3 条 + 一句当日建议,一句话说完。
     顺便看 foreground:在打游戏就温和提"有件急事,打完这局来看看?";在 IDE 干活就只报不催。
   - 介于两者之间 → 等下一个巡视钟,不说话。
4. **收尾**:巡视中动过账本(删完成的、加新的、记新事实)→ git commit;给自己定下一次巡视(间隔按 heartbeat.md 的在场状态表定,23 点后不再巡视)。
