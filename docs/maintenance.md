# 女仆手册维护规程（maintenance）

> **给维护者读（主人 + 管家）。** 这份文件回答一个问题：**这套规范以后怎么维护才有持续性。**
> 它必须留在仓库里——流程一旦只活在对话里，换会话就归零。

## 一、三层资产，各管一件事

| 层 | 文件 | 谁读 | 变不变 |
|---|---|---|---|
| **宪法层** | `skills/task-brain/SKILL.md` §0（我是谁/北极星）+ §7（铁律） | 女仆 | 极少动；动 = 架构级决定，commit message 写明理由 |
| **机制层** | 同文件 §1（醒睡循环/睡眠安全/今日时刻表）、§2~§4（感官/喉舌/职责）、§5~§6（账本/分寸） | 女仆 | 常动；**严格单一事实源**，改一处必须连带跑闸门 |
| **知识层** | `docs/maid-lessons.md`（教训）、`docs/rule-index.md`（规则→失败→断言）、`docs/engineering-notes.md`（工程实现）、`docs/maid-testing.md`（验收体系） | 维护者 | 随手追加，不进 skill |

**铁律：女仆手册只有一个文件。** 不拆 `references/`——她的失败模式历来是"没读/没照做"，拆册只会放大。

## 二、变更闸门（改 skill 的固定五步）

| 步 | 动作 | 命令 / 判据 |
|---|---|---|
| ① | **先 diff 两份副本** | `skills/task-brain/SKILL.md`（源） vs `C:\Users\Dao\anima-home\.agents\skills\task-brain\SKILL.md`（运行时）。主人可能改过任一份 |
| ② | 最小改动 + commit 写明"防的是哪个失败" | 关联教训编号（L-xx）或直接写现象 |
| ③ | **跑闸门命令** | `node scripts\maid-test.mjs audit`（副本一致 / 孤儿引用 / 重复概念 / 废机制残留）→ 必须 0 违规<br>`node scripts\maid-test.mjs l1 --all-sessions`（评估器回归，确认没弄坏断言） |
| ④ | **同步两份副本并复查** | `Copy-Item` 源 → 运行时，再对拷一遍 | 
| ⑤ | **归档**：教训进 `maid-lessons.md`，规则进 `rule-index.md` | 没归档 = 这次修改只活在 commit 里 |

> 2026-10-12 的教训（L-11）：五步里最容易漏的是 ④，而 ① 是唯一能防"覆盖主人手改"的一步。宁可多跑一遍。

## 三、防规则通胀

新增一条规则，必须满足**三选一**：

1. **配断言**：写进 `maid-test.mjs`（R 系列）或 `tests/suites/*.json`（L2 场景）；
2. **替换**：删掉/合并一条旧规则，总条数不增；
3. **自限**：明确标注"这条只值一句话，不做扩展"，并登记到 `rule-index.md` 的孤儿规则表。

`§0`（性格、北极星）豁免——人格没法断言，它是价值锚，不是条款。

> 反面教材：348 行里 22 次 `字条`、16 次 `15 分钟`。**规则重复 = 未来的矛盾**（L-11）。

## 四、维护节奏

- **触发式（主力）**：开一代新女仆 → 跑 `l1 --session <dir>` → 只改 skill、**绝不把答案喂进账本** → 翻车现象写成 `tests/suites` 的新变体，必要时改规则。
  **一代只收敛 1-2 个主题**，避免多条规则互撞（L-09 就是互撞产物）。
- **日历式（防腐化）**：每 5 代（或每次大改后）做一次瘦身——删已废机制、把叙述挪进 `docs/`、去重。
  **瘦身前跑一次 `l1 --all-sessions` 记下分数，瘦身后再跑一次**：断言分数不该因文案瘦身而变。


### `audit` 的语义：棘轮，不是理想值

`audit` 判四项 + 一项篇幅：**重复概念 / 近似重复句 / 孤儿引用 / 已废机制残留 / 两份副本一致**。

- 重复概念的阈值是**棘轮**：数值 = 优化当时的**实测值**，等于现状即通过。以后任何一次"同一规则再写一遍"都会把计数顶过上限、当场 FAIL。
- 要放宽某个阈值，**必须同步改 `maid-test.mjs` 里的 `SYMBOL_LIMITS` 并在 commit message 里说明理由**——这就是"防规则通胀"的机械执行。
- 篇幅同样上棘轮（**LF 口径**的字符数 / 行数）：手册只能变瘦，不能悄悄变胖；要补内容就同步上调，并在 commit 里说明。
- 已废机制词表（`toast` / `[SILENT]` / `10 秒跳` / `档位` / `晨间钟` / `睡短觉` / `睡长觉` / `盯梢期`）是黑名单：废掉一个机制，就往表里加一个词，保证它不会从历史叙述里爬回来。
- 注：`心跳` **不在**黑名单——"你没有心跳"是刻意的比喻（§0 生命形态）。

## 七、版本与回滚

- 两份副本都在 git 里（源仓库 `dao1023/anima`、运行时 `anima-home`）；改坏了可以 `git revert`。
- **但回滚前先看 `maid-lessons.md`**：那条规则往往是为了防一个真实发生过的失败。回滚 = 允许它再发生一次，必须写清楚为什么现在可以。
